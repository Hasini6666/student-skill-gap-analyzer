# Student Skill Gap Analyzer

A web-based application that analyzes students' skills, identifies skill gaps for target software roles, and provides personalized learning roadmaps.

## Problem Statement
Many students struggle to understand what skills they are missing for software roles. This project helps students compare their current skills with industry requirements and receive a structured learning roadmap.

## Features
- Student skill input
- Target role selection
- Skill gap analysis
- Readiness score generation
- Personalized learning roadmap
- Recommended technologies and projects

## Example Use Case
Input:
- Skills: Java, HTML, CSS
- Target Role: Java Developer

Output:
- Missing Skills: Spring Boot, SQL, REST APIs, Git, DSA
- Readiness Score: 55%
- Suggested Learning Path
